# Fiktiv Naturdestination
Den här webbplatsen ska föreställa en startsida för en fiktiv naturdestination. Den fokuserar på att framhäva naturupplevelser, paddling, vandring samt att kunna planera ett besök genom knapptryckning. 

## Tekniker
Projektet är byggt med:  
-HTML  
-CSS
